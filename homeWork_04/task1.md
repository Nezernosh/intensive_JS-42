**Какие бывают алгоритмы сортировок?**

- **Сортировка пузырьком (Bubble Sort):**
  - **Описание:** В этой сортировке мы на каждом шаге находим наибольший элемент из двух соседних и ставим этот элемент в конец пары.
  - **Сложность:** O(n²)
  - **Особенности:** Простой в реализации, но неэффективен для больших наборов данных.

- **Сортировка выбором (Selection Sort):**
  - **Описание:** На каждой итерации выбирает минимальный (или максимальный) элемент из неотсортированной части и помещает его в начало.
  - **Сложность:** O(n²)
  - **Особенности:** Число перестановок минимально, но алгоритм все равно медленный.

- **Сортировка вставками (Insertion Sort):**
  - **Описание:** Строит отсортированный список, добавляя по одному элементу и вставляя его в нужную позицию.
  - **Сложность:** O(n²)
  - **Особенности:** Эффективен для небольших или частично отсортированных массивов.

- **Быстрая сортировка (Quicksort):**
  - **Описание:** Выбирает опорный элемент и разделяет массив на два подмассива, сортируя их рекурсивно.
  - **Сложность:** O(n log n) в среднем, O(n²) в худшем случае
  - **Особенности:** Очень эффективен для больших массивов, но зависим от выбора опорного элемента.

- **Сортировка слиянием (Merge Sort):**
  - **Описание:** Делит массив пополам, сортирует каждую половину и затем сливает отсортированные половины.
  - **Сложность:** O(n log n)
  - **Особенности:** Стабильный алгоритм, но требует дополнительной памяти.

- **Пирамидальная сортировка (Heapsort):**
  - **Описание:** Преобразует массив в двоичную кучу и извлекает максимальный элемент, перестраивая кучу после каждого извлечения.
  - **Сложность:** Гарантированный O(n log n)
  - **Особенности:** Не требует дополнительной памяти, но не является стабильным.

- **Сортировка подсчетом (Counting Sort):**
  - **Описание:** Использует массив счетчиков для хранения количества каждого уникального элемента.
  - **Сложность:** O(n + k), где k — диапазон входных значений
  - **Особенности:** Эффективен для целых чисел в ограниченном диапазоне.

- **Поразрядная сортировка (Radix Sort):**
  - **Описание:** Сортирует числа по разрядам, начиная с младшего к старшему.
  - **Сложность:** O(w * n), где w — количество разрядов
  - **Особенности:** Подходит для числовых данных.

- **Сортировка Шелла (Shellsort):**
  - **Описание:** Улучшение сортировки вставками с использованием промежутков между элементами.
  - **Сложность:** От O(n log² n) до O(n²)
  - **Особенности:** Производительность зависит от выбранной последовательности промежутков.

Существует множество алгоритмов сортировки, каждый из которых имеет свои особенности, преимущества и недостатки. Каждый алгоритм выбирается в зависимости от конкретных требований к скорости, потреблению памяти и характеру данных.
